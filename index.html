云盘 Excel 总表

填写本机上由云盘（OneDrive、SharePoint、坚果云、百度网盘等）自动同步的文件夹，或其中某个 .xlsx 文件。在「上传识别 › 上传到云端总表」确认后，按合同ID更新已有行、追加新行，再由云盘自动同步；合同列表与检索也会搜索这个总表里他人上传的合同。

填文件夹时总表名为「合同识别总表.xlsx」。每次合并前自动备份为「…备份.xlsx」；总表里手动加的列会保留。

上传人名称

本机上传的合同记录为这个上传人，并写入云盘总表的「上传人」列，用于区分「我上传 / 他人上传」。留空则使用本机 Windows 账户名。已上传合同的上传人不随修改变化。

关于本系统

OCR 和关键词分析在本机运行

  • PDF 解析引擎： 原生版 PyMuPDF / 浏览器版 PDF.js（含中文字符映射）
  • 扫描件 / 图片 OCR： PaddleOCR PP-OCRv4（原生 CPU / 浏览器离线）
  • 业务语义匹配： 原生版内置 BGE 中文模型，识别业务表述
  • 图表引擎： Apache ECharts
  • 本地存储： 原生版：程序旁文件夹内的 JSON 数据及原文件；浏览器版：IndexedDB
  • 运行模式： 本机原生进程 / 浏览器备用 · v2.15.0
  • 隐私保护： 云盘总表由指定同步目录提供，合同原件及识别全文保存在本机
